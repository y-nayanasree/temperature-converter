# Temperature Converter

A simple and responsive Temperature Converter built using HTML5, CSS3, and JavaScript.

## Features

- Convert Celsius to Fahrenheit
- Convert Celsius to Kelvin
- Convert Fahrenheit to Celsius
- Convert Fahrenheit to Kelvin
- Convert Kelvin to Celsius
- Convert Kelvin to Fahrenheit
- Displays results with two decimal places
- Input validation for empty values
- Responsive design for mobile and desktop
- Modern blue and cyan glass-style interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

The user enters a temperature, selects the input unit, and chooses the required conversion.

JavaScript performs the temperature conversion using standard mathematical formulas and displays the result dynamically on the webpage.

## Conversion Formulas

### Celsius to Fahrenheit
`°F = (°C × 9/5) + 32`

### Fahrenheit to Celsius
`°C = (°F - 32) × 5/9`

### Celsius to Kelvin
`K = °C + 273.15`

### Kelvin to Celsius
`°C = K - 273.15`

### Fahrenheit to Kelvin
`K = (°F - 32) × 5/9 + 273.15`

### Kelvin to Fahrenheit
`°F = (K - 273.15) × 9/5 + 32`
